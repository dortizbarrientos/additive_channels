# Supplementary File 1: mathematics guide

**[Read the mathematics guide](guide.pdf).** It starts with one trait and works through conditional expected reproduction, the variance share, reproductive weighting and the stated inheritance model. Worked answers and optional multivariate sections provide the detailed calculations.

For a shorter introduction to the argument, read the [companion](../companion/companion.pdf). The [worked estimation example](../../examples/estimating_variance_share/worked_example.pdf) connects the quantities to simulated observations.

The editable source is [guide.tex](guide.tex), with [references.bib](references.bib) and five [figure PDFs](figures/). To regenerate the figures and compile the guide from the repository root:

```bash
bash run_all.sh --tutorials
```

See [REPRODUCING.md](../../REPRODUCING.md#teaching-pdfs-and-slides) for the TeX dependencies. The [result catalogue](../../RESULTS.md) maps the guide's calculations to their independent numerical checks.
